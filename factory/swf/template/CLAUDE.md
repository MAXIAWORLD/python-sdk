# Agent rules (token-frugal)
- Data model: `app/schema.json` only. Business rules: `app/hooks/<entity>.py` only. Custom tests: `tests/test_custom_<entity>.py`.
- NEVER edit managed files: app/main.py, app/static/index.html, tests/test_api.py, Dockerfile, CI (regenerated by `swf gen`).
- Hooks: `before_create(data)->data`, `before_update(data, current)->data`, `after_create(item)`, `before_delete(item)`; reject with `fastapi.HTTPException(422, msg)`.
- If a hook rejects generic sample data, set `TEST_SAMPLE = {...}` in that hook file.
- Verify: `python -m swf validate .` (lint+security, tests, smoke). Read only files you need; no long explanations.
